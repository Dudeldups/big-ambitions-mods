# BMW M4 Competition Coupé with M xDrive (G82) targets

The prefab and runtime tune target BMW's May 2021 G82 M4 Competition Coupé with
M xDrive technical data.

| Item | Target |
| --- | ---: |
| Length / width / height | 4,794 / 1,887 / 1,394 mm |
| Wheelbase | 2,857 mm |
| Track, front / rear | 1,617 / 1,605 mm |
| Ground clearance | 121 mm |
| DIN curb mass | 1,775 kg |
| Fuel / luggage | 59 L / 440 L |
| Engine | 2,993 cc S58 twin-turbo inline-six |
| Power / torque | 375 kW (510 hp) / 650 Nm |
| Idle / redline | 800 rpm tuning target / 7,200 rpm official redline |
| Transmission | Eight-speed M Steptronic with Drivelogic |
| Ratios 1–8 | 5.000, 3.200, 2.143, 1.720, 1.313, 1.000, 0.823, 0.640 |
| Reverse / final drive | 3.478 / 3.154 |
| Tires, front / rear | 275/35 ZR19 / 285/30 ZR20 |
| 0–100 km/h | 3.5 s |
| Top speed | 250 km/h; 290 km/h with M Driver's Package |
| Launch MSRP reference | USD 74,700 plus destination for the Competition RWD; mod price USD 79,795 for the xDrive target |

Primary references:

- BMW Group PressClub, May 2021 technical specification:
  https://www.press.bmwgroup.com/middle-east/article/attachment/T0333031EN/479621
- BMW Group PressClub, September 2020 launch release and pricing:
  https://www.press.bmwgroup.com/usa/article/detail/T0317577EN_US/the-new-2021-bmw-m3-sedan-and-m4-coupe

The 800 rpm idle value is a tuning assumption because the cited BMW technical
sheet specifies the 7,200 rpm redline but does not publish a nominal idle speed.
