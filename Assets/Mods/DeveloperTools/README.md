# Developer Tools

Developer/testing utility mod for Big Ambitions. The testing window defaults to `F10`; its UI, quick-money, and quick-needs hotkeys can be changed in the normal mod options.

The vehicle catalog refreshes each time the window opens. The vanilla item catalog is populated lazily and cached. City-map teleport input only runs while the map is open. Time advancement uses the game's `TimeMachine`, so normal hourly and daily simulation ticks continue to run.
